☁ Cloud Storage (GitHub Gist)
All your data (AR, AP, FAR, Weekly grid, settings) is saved to a private GitHub Gist as the source of truth. Your browser keeps a local cache for speed and offline use. Setup is one-time. ▸ How to set this up
  1. Go to gist.github.com and sign in.
  2. Create a new gist: filename ai3_cashflow_data.json, content {}. Click Create secret gist (NOT public).
  3. From the gist URL, copy the long ID (e.g. a1b2c3d4e5f6…) — that's your Gist ID.
  4. Go to github.com/settings/tokens → Generate new token (classic).
  5. Name it "ai3 cashflow", expiration 1 year. Under scopes, check ONLY gist. Generate, copy the token (starts with ghp_).
  6. Paste both below, click Test connection, then Save & use.
